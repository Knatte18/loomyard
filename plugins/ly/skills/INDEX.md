# ly Skills

| Skill | Description |
| --- | --- |
| [board](board/SKILL.md) | Read or write the board — create or promote an entry, find or list entries, prune done ones — always through `lym board`, never by touching the board's JSON files in the Bolt checkout. |
| [board-policy](board-policy/SKILL.md) | The policy for keeping the board on the operator's behalf — one finding per note, a body holds the current design only, propose bundles and wait for approval, release only on a named go-ahead. |
| [cli](cli/SKILL.md) | Load the index of every `lym` command an operator may use into the session. |
| [distill](distill/SKILL.md) | Request a compact cycle of the orch session through `lym orch distill`. |
| [refresh](refresh/SKILL.md) | Request a clear cycle of the orch session through `lym orch refresh`. |
