## Findings

### [BLOCKING] Card 3's temporary banned-import proofs will not compile as described
**Location:** Batch 1, Card 3
**Issue:** Adding a plain (non-blank) import of `internal/output`/cobra/`internal/*cli`/`internal/clihelp`/`internal/lyxcwd` to `probe.go`, or `internal/lock`/`internal/configengine`/`gopkg.in/yaml.v3` to `lspclient.go`, is unused in either file, so Go's "imported and not used" compiler error fails the whole package build before any test runs — `go test` reports a build failure, not the seam test's own `t.Errorf` naming the specific predicate, and the lyxcwd non-regression proof can never "stay green" since nothing in the package can run at all.
