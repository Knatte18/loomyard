## Findings

### [BLOCKING:design] Reap log suppressed after a partial kill
**Location:** batch 1 / card 3 **Issue:** the card requires the `logger.Info` line "on the success path only — an early `return killed, err` from a failing `kill-pane` must not log", but `reconcileLocked` reaches that early return *after* having already killed the earlier ids in `plan.deadPanesToKill`/`plan.untrackedPanesToKill`, and every caller discards the returned `killed` slice on error (`spawn.go:231-234`, `lifecycle.go:738-741`, and card 6's new `fmt.Errorf("reconcile: %w", err)` site) — so a partial reap destroys panes with no trace anywhere, which is the exact shape the-reap-logs-what-it-destroys exists to prevent. **Fix:** state a disposition for the partial-kill path (log what was killed before returning the error, or record why silence there is acceptable) rather than making the log unconditionally success-only.

### [NIT:scope] Card 7's Context omits overlay.go
**Location:** batch 2 / card 7 **Issue:** the card's `Requirements:` names `e.tmux.execHook`, declared in `internal/reedengine/overlay.go`, which is absent from card 7's `Context:` — card 3 lists overlay.go for the same identifier and even explains the `capture bool` seam there. **Fix:** add `internal/reedengine/overlay.go` to card 7's `Context:` for parity with card 3 (mitigated today only because the listed `lifecycle_test.go` happens to show the hook shape and the 6-field `list-panes` line format at `:392`).

### [NIT:consistency] Card 14 preserves an already-false sole-pane premise
**Location:** batch 4 / card 14 **Issue:** the card scopes the rewrite of `TestSmokeRemoveLastStrandThenAddRunsTheNewCommand` to "only the adoption framing" and justifies keeping the rest with "the sole pane is corpsed by `kill-pane`" — but the always-present header pane is never in `removeStrandLocked`'s returned `paneIDs` (`strand.go:241-256`, killed at `:499`), so the removed strand's pane is never the session's sole pane and the corpse the doc comment and skip string describe no longer arises. **Fix:** either give that premise a disposition too or drop the "sole pane is corpsed" justification, so the rewritten comment does not restate a precondition the header made unreachable in an earlier round.
