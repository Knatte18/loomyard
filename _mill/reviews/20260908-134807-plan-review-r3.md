## Findings

### [BLOCKING:design] Real descriptors ship untested; fixture mitigation is false
**Location:** batch 1 card 5, with batch 2 cards 6 and 7
**Issue:** card 5 asserts every per-CLI wording verbatim against `websterFixture`/`burlerFixture` declared *inside* `cliwire`, and justifies that with "a divergence between a fixture and its real descriptor is caught by each CLI package's own composition tests plus the two integration files" — but cards 6 and 7 delete every test that touched the nested-geometry refusal, and grepping the tree shows no test anywhere (including both `cli_integration_test.go`) asserts `StateArtifacts`, `TargetRole`, `TargetRecourse`, `HubTargetSubject`, `Name`, or `MissingPlanRefusal` text; the surviving `TestWire_TargetDirRefusedInHubMode` only checks the error contains `--target-dir`.
The Shared Decision "a reworded message fails the suite" is therefore untrue of the six new descriptor fields, which are exactly the values the task converts from inline production strings into free-floating data.
**Fix:** add to card 6 and card 7 a per-package test pinning that package's own `wireModule`-produced refusals verbatim (or reach the real descriptors from `cliwire`'s tests via each CLI's own test file), and correct card 5's mitigation sentence.

### [NIT:scope] cliwire's named test helpers cannot yield `stateDir`
**Location:** batch 1 card 5
**Issue:** `setStandaloneStateRoot(t)` is specified to return nothing and `hash8For` returns only `hash8`, yet every listed case that drives `ResolveStandalone` needs `stateDir` — to seed the default plan dir, to assert `standalonegeom.LogsDir(stateDir)`/`StencilsDir(stateDir)`, and to make the derived stencils path uncreatable.
**Fix:** name burler's existing `hash8AndStateDir(t, target) (stateDir, hash8 string)` in the helper list alongside `hash8For`.

### [NIT:consistency] `module.go` doc comments reinstate the per-CLI text
**Location:** batch 1 card 3
**Issue:** card 3 requires each `Module` field's production doc comment to spell out "Webster's value is …; burler's is …", putting both callers' exact noun phrases back inside the shared module — against the Shared Decision's "no production file under `internal/cliwire` names `webstercli` or `burlercli`" and card 3's own "do not name either caller package in any production file here".
