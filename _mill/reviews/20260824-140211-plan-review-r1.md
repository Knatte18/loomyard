## Findings

### [BLOCKING:design] Card 14 inserts DiscussionWrite at the wrong sorted position
**Location:** batch 3, card 14 (`internal/shedrecipe/registry_test.go`).
**Issue:** Card 14 instructs inserting `"DiscussionWrite"` "between `BurlerRound` and `DiscussionValidate`", but byte-wise string sort puts `"DiscussionValidate"` before `"DiscussionWrite"` (`'V'` < `'W'`), so the true sorted slot is between `DiscussionValidate` and `Finalize`. Since `TestRegistry_ShipsThirteenEntries` compares `want` element-by-element against `Names()` (which sorts the real registry), following the card literally makes the renamed test fail, breaking batch 3's own `verify`.
**Fix:** Correct the card to insert `"DiscussionWrite"` immediately after `"DiscussionValidate"`, before `"Finalize"`.

### [BLOCKING:scope] buildSequenceFixture's new return arity breaks four untouched call sites
**Location:** batch 3, cards 16 and 19 (`internal/loomrecipe/fixture_test.go`, `resume_test.go`).
**Issue:** Card 16 changes `buildSequenceFixture`'s signature to also expose the fixture's shuttle and commit-counter handles (a 4th return value or a wrapping struct). Card 19 only updates the two bounce-routing tests' `_, env, paths := buildSequenceFixture(t)` call to the new arity. `resume_test.go` has four more call sites (`TestResume_DoesNotRestartAtRowOne`, `TestResume_CrashRecoveryRecallsUnconditionally`, `TestResume_PauseStopsAtBoundaryAndClearsFlag`, `TestBounceRouting_EmptyTargetBlocksInstead`) still using the old 3-value form, which fails to compile once the return arity changes — Go requires an exact match on `:=` multi-assignment.
**Fix:** Card 19 (or a new card) must update all six `resume_test.go` call sites' destructuring to the new arity, not only the two whose behavior changes.

### [BLOCKING:scope] New wiring_test.go case evaluates DiscussionSpec() without seeding the stencils dir
**Location:** batch 3, card 22 (`internal/loomcli/wiring_test.go`).
**Issue:** Card 22's second test calls `c.env.DiscussionSpec()` and asserts on `Prompt`/`OutputFiles`/etc. That closure calls `loomengine.DiscussionSpec` → `composePrompt` → `stencilstore.Read(websterGeom.StencilsDir, "loom-template-discussion")`, and `stencilstore.Read` hard-errors on a missing file (verified: no fallback, no lazy seed). `hubLocation`'s fixture only seeds `<anchor>/_lyx/config/{loom,landing}.yaml`, never `<hub>/_board/_lyx/stencils/loom/loom-template-discussion.md`, so the closure returns an error and every assertion on the Spec is unreachable. Card 22's Context omits `internal/stencilstore` and any seeding helper.
**Fix:** Add a step (or a helper mirroring `internal/loomengine/prompt_test.go`'s `newTestStencilsDir`) that seeds the embedded discussion stencil under the hub's `_board/_lyx/stencils/loom/` before evaluating `c.env.DiscussionSpec()`.
