Card 31 asserts both the refusal (including that it works outside a git worktree, proving it runs before arming) and the table's own sets.

- r4 holistic, "Cards 24 and 32 contradict on `longlist_test.go`" (NIT) — card 32 restated to match card 24 and the source: the test asserts `root.Long` names every registered top-level module, derives its module set from the live tree, and holds no snapshot, so it can neither catch a reflowed verb `Long` nor be regenerated.
