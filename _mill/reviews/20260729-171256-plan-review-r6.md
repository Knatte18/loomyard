## Findings

### [BLOCKING] Supervised daemon anchoring is cwd-fragile outside a lyx hub
**Location:** batch 4 / card 12 (the flip), no Shared Decision covers it
**Issue:** `cli.go` leaves `worktreeRoot` `""` whenever `hubgeometry.Resolve(cwd)` fails (an explicitly supported "outside a hub" path — falls back to `BuiltinRegistry()`). After card 12 flips Go to supervised-first, `ensureSupervised` then resolves `hubgeometry.Layout{WorktreeRoot: ""}.CodeintelDaemonStateFile("go")` to the relative path `.lyx/codeintel/go/daemon.json`, anchored to whatever the process's cwd happens to be rather than `--target-dir`. Two invocations against the same `--target-dir` from different cwds get different (or colliding, or littering) daemon state — defeating the "session-long daemon" goal this task exists to deliver, for a first-class supported usage mode. Card 14 fixes this exact class of bug for one test fixture (`TestReferences_Integration`) but no card addresses the equivalent production gap.
**Fix:** Add a Shared Decision (or a card) covering the empty-`WorktreeRoot` case — e.g. derive `worktreeRoot` from `--target-dir`'s own git root when hub resolution fails, or document/accept the cwd-relative fallback explicitly rather than leaving it unaddressed.

### [BLOCKING] Card 1 Context omits lspclient.go for a cited function
**Location:** batch 1 / card 1
**Issue:** Requirements ask the doc comment to state `KillPID` "is distinct from `lspClient.kill()` (which kills a spawned `*exec.Cmd`...)" — `lspClient.kill()` is defined in `internal/codeintelengine/lspclient.go`, which is not in card 1's `Context:` (only `daemonstate.go`) or `Edits:`.
**Fix:** Add `internal/codeintelengine/lspclient.go` to card 1's `Context:`.

### [BLOCKING] Card 12 Context omits lspclient.go for a cited function
**Location:** batch 4 / card 12 (native-fallback coverage test)
**Issue:** Requirements assert the fallback test spawns no subprocess because "native's `newLSPClient` fails at `exec.LookPath` ... before any `cmd.Start`" — `newLSPClient` is defined in `internal/codeintelengine/lspclient.go`, not listed in card 12's `Context:` or `Edits:`. The test's process-free claim depends on this file's exact behavior.
**Fix:** Add `internal/codeintelengine/lspclient.go` to card 12's `Context:`.

## Verdict

REQUEST_CHANGES
One real design gap (supervised daemon anchoring outside a hub) plus two Context-completeness omissions.
