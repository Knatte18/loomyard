## Findings

### [BLOCKING] Stale ensureSupervised godoc sentences unnamed
**Location:** Batch 4, cards 10–12
**Issue:** The cards enumerate doc updates meticulously but omit three `ensureSupervised` doc-comment sentences in `ensureserver.go` that this batch makes false: "gopls's own -listen.timeout, left unconfigured here, defaulting per gopls itself" (card 10 configures it via `supervisedArgv`), "The daemon this function spawns is never killed by its caller" (card 11's escalation calls `proc.KillPID` on it), and the intro's "no V1 registry entry requests it yet" (card 12 flips dispatch). The plan's own rationale calls stale strategy prose after the flip a defect; card 12 names only the "Known limitation" paragraph.
**Fix:** Name these three sentences in cards 10, 11, and 12 respectively as required doc edits.

### [NIT] KillPID error handling unspecified in escalation
**Location:** Batch 4, card 11
**Issue:** If the daemon dies between the failed under-lock re-dial and the kill, `proc.KillPID(state.PID)` returns an error (ESRCH/ErrProcessDone); the card is silent, so an implementer returning it verbatim aborts a respawn that should proceed.
**Fix:** State that the escalation's `KillPID` is best-effort — ignore/log a dead-PID error and continue to the respawn.

### [NIT] No documentSymbolProvider capability gate on InFile branch
**Location:** Batch 2, card 4
**Issue:** The workspace/symbol resolver gates on `supportsWorkspaceSymbol()` → `ErrResolverUnsupported`, but the new `InFile` branch issues `documentSymbol` unconditionally, so a non-advertising server (legacy cold-spawn languages are reachable via `--in-file`) surfaces a raw LSP error instead of the typed vocabulary.
**Fix:** Either add the capability check (retain `documentSymbolProvider` in `capabilities`) or note the accepted asymmetry in the card and method doc comment.

### [NIT] Fallback-test stub mechanism is Linux-only; lock dir not created
**Location:** Batch 4, card 12
**Issue:** `resolveGoToolchain` stats `gopls.exe` on Windows (the primary dev OS per `tierpurity_test.go`), so a stub written to `filepath.Join(destDir, "gopls")` is never found — the fake installer runs twice and the failure becomes `exec.ErrNotFound`, not the described non-executable-LookPath failure (assertions still pass only coincidentally); also `lock.AcquireWriteLock` on the daemon lock needs an explicit `MkdirAll` since no state write creates the directory.
**Fix:** Instruct writing the stub under the platform binName (`gopls.exe` on Windows) and add the `MkdirAll`-before-lock step.

### [NIT] Context omissions in cards 13/14
**Location:** Batch 5, cards 13 and 14
**Issue:** Both cards' Requirements use `builtins()` (defined in `registry.go`) and card 14 uses `ErrAmbiguousSymbolSentinel` (`errors.go`), yet neither file is in Context/Edits — mitigated because the identifiers appear verbatim and are already used in the edited files.
**Fix:** Add `internal/codeintelengine/registry.go` (both cards) and `internal/codeintelengine/errors.go` (card 14) to Context.
