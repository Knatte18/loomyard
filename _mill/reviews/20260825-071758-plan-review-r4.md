## Findings

### [BLOCKING:design] Interstitial fixture has no marker-discovery fallback
**Location:** batch 1 / card 2. **Issue:** `_mill/discussion.md`'s own Gotchas note the `www` interstitial's challenge text "only appears after JS runs," yet card 2 hardcodes 8 fixed marker strings (led by `"prove your humanity"`) with no instruction to verify one actually appears in the captured `reddit-www-interstitial.html` bytes — unlike the login-wall marker, which gets an explicit "read the fixture, pick a distinctive substring" step. **Fix:** Give the interstitial the same read-and-pick (or verify-first) treatment as the login-wall marker, or state which of the 8 seeded markers is confirmed present in the actual captured static bytes.

### [NIT:consistency] redditListing/redditChild field casing diverges from redditThing's
**Location:** batch 2 / card 5. **Issue:** Card 5 describes `redditListing`/`redditChild` with lowercase field names (`data`, `children`, `kind`) while `redditThing`'s fields are given capitalized (`Title`, `Selftext`, ...); read literally, unexported Go fields would silently fail to populate via `encoding/json`. Card 5's own Context (`hackernews.go`) models the correct exported-field-plus-tag pattern, which mitigates but doesn't remove the ambiguity. **Fix:** State the Go field names for `redditListing`/`redditChild` in the same exported-with-json-tag form used for `redditThing`.

### [NIT:consistency] fetcher.go's struct doc comment not updated for doNoRedirect
**Location:** batch 3 / card 7. **Issue:** `fetcher`'s doc comment already says "Both fields must be set before use," stale even today (3 fields exist); card 7 adds a fourth required function field (`doNoRedirect`) without updating that comment, and the card's own "unset field is a wiring bug" framing makes the comment's accuracy more load-bearing, not less. **Fix:** Add a one-line update to `fetcher`'s doc comment noting `doNoRedirect` alongside `do`/`browser`.

### [NIT:consistency] Card 7's Context includes browser.go with no evident use
**Location:** batch 3 / card 7. **Issue:** Card 7's `Context:` lists `plugins/prowler/browser.go`, but none of the card's Requirements reference anything in it (the redirect-suppression seam only touches `fetcher.go`/`headers.go`/`main.go`/`fetch_test.go`). **Fix:** Drop `browser.go` from Context or state why it's needed.
