## Findings

### [BLOCKING] Test-relocation leaves cross-package helpers undefined
**Location:** Batch 1 / Card 3 (root cause in Card 2's Moves)
**Issue:** `writeFile` (defined in `state_test.go`, which moves wholesale to `treadleengine`) and `stringSlicesEqual` (defined in `roundfiles_test.go`, also moving) are both called by `run_test.go` (confirmed at lines 1345, 1474, 1621 and 241, 245), which Card 3 pins as staying in `package perchengine` with exactly two named fixes — neither restores these helpers, so `run_test.go` fails to compile. Symmetrically, `intSlicesEqual` (defined only in `profile_test.go`, which stays untouched in perchengine) is called by `TestLoadOrInitState`/`TestSaveState_ReadJSONRoundTrip` (lines 34, 174) — both of which Card 3 keeps inside the moved bulk of `state_test.go`, now `package treadleengine` — so that file fails to compile too. Card 3's own text ("replace its two uses of moved unexported symbols") undercounts the actual cross-file dependencies.
**Fix:** Card 3 must additionally duplicate (or inline) `writeFile`/`stringSlicesEqual` into a perchengine-side test file and duplicate/inline `intSlicesEqual` into the moved `treadleengine/state_test.go`; the differential-test-bar decision's "mechanical package-split fallout" clause already licenses this, it just needs to be named.

### [BLOCKING] buildRoundProfile's param type moves; its test isn't verbatim
**Location:** Batch 1 / Card 2 (adapter.go) and Card 3 (adapter_test.go)
**Issue:** Card 2 moves `roundArtifactPaths` (the type) and `artifactPaths` (the func) to `treadleengine`, unexported there, while extracting `buildRoundProfile` — which currently takes a `roundArtifactPaths` parameter (`roundfiles.go:65`) — into `perchengine/adapter.go`, without ever pinning the new parameter list. Card 3 then claims `TestBuildRoundProfile_FieldMapping` moves "verbatim" into `adapter_test.go`, but that test's own body calls `artifactPaths(filepath.Join("run","dir"), 3, 1)` (`roundfiles_test.go:103`) to build its `paths` argument — a call perchengine can no longer make once that helper lives, unexported, in a different package.
**Fix:** Card 2 should pin `buildRoundProfile`'s post-extraction signature (e.g. plain `ReviewPath`/`FixerReportPath` strings sourced from `AttemptInput`, not a `roundArtifactPaths` struct), and Card 3 should acknowledge the extracted test's fixture construction needs rewriting, not a verbatim copy.

### [NIT] Card 13 fixture example covers only one of two key-pairs
**Location:** Batch 4 / Card 13
**Issue:** Card 13 spells out migrating `judge-model`/`judge-effort` to `judge-model: "haiku[effort=low]"`, but the same two `run_test.go` fixtures (lines ~102-105, ~221-224) also carry `model: sonnet` + `effort: high`, which the batch scope says must migrate too; no analogous example is given for that pair.
**Fix:** State explicitly that both key-pairs in each fixture migrate (e.g. `model: "sonnet[effort=high]"`), not just the judge-model one illustrated.
