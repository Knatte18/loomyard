## Findings

### [BLOCKING:design] `DetectCrashResume`'s `slug` parameter is unsourced and duplicates `EntryObservation.Slug`
**Location:** Batch 2 card 5 (`DetectCrashResume` signature) / Batch 3 card 7 (`detectAndFileAnomalies`'s ctx-done exception)
**Issue:** Card 5 declares `func DetectCrashResume(entry EntryObservation, slug string) (Anomaly, bool)` with a separate `slug` argument, even though `EntryObservation` already carries its own `Slug` field, and card 5's own text for `DetectAnomalies` states the crash-resume `Anomaly`'s `Slug`/`Parent` "take them from entry" (not from a passed-in value). Card 7's `selfreportDeps` (the sole external caller's inputs) has no independent slug field, so the one direct call site — the ctx-done branch, which has no `product`/`final` in hand — has no stated source for the second argument other than `entry.Slug` itself, making the parameter's purpose, and whether it must ever differ from `entry.Slug`, unspecified.
**Fix:** Either drop the redundant `slug` parameter and have `DetectCrashResume` read `entry.Slug` internally, or state explicitly (in card 5 and card 7) that every caller passes `entry.Slug` verbatim and explain why a value already carried on `entry` is also threaded as a bare parameter.

### [NIT:consistency] Collapse's "first occurrence" tie-break is unreachable by construction
**Location:** Batch 3 card 7, filing pass step one (collapse by title)
**Issue:** Only recurring-finding anomalies carry a non-zero `Round` (per card 5, the five trigger-5-only fields are zero for the other four kinds), and `DetectAnomalies` returns at most one crash-resume and one halt-kind anomaly per call with titles that never collide with each other or with a recurring-finding title's shape — so two same-titled non-recurring-finding anomalies can never appear in one pass, making the stated "keep the first occurrence otherwise" branch dead code the plan does not flag as such (unlike burler.go's own explicit "Unreachable" comments for the analogous case).
**Fix:** Note in card 7 that the "otherwise" branch is unreachable-by-construction, or drop it from the requirement.
