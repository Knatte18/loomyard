## Findings

### [BLOCKING:design] header.go's blocking tail can fall through to a JSON envelope on the pane's own console
**Location:** `internal/reedcli/header.go:80-109`
**Issue:** The `if blocking { ... }` block ends at `headerPark()` with no `return` before the closing brace. If `headerPark()` ever returns — which it demonstrably does under test (`header_test.go`'s `stubHeaderTail`) and which the design explicitly treats as a substitutable seam, not merely a theoretical case — execution falls through to the unconditional `clihelp.SetExit(cmd.Context(), output.Ok(out, map[string]any{"text": text}))`, writing `{"text":"...","ok":true}` onto `out` (the pane's own stdout/screen). This directly violates the stated invariant that "the pane's stdio is its screen" and that a watch-loop return is "logged only, never anything written to stdout or stderr" — the same class of failure the surrounding comments say `headerPark()`'s unconditional call exists specifically to prevent, one level up (protecting against `Watch` returning, but not against `headerPark` itself returning).
**Fix:** Add `return nil` as the last statement inside the `if blocking { ... }` block, immediately after `headerPark()`, so the tail can never reach the JSON-envelope write once it has entered blocking mode.

### [NIT:consistency] Card 20's keepalive-survival test assertion doesn't actually detect the envelope leak
**Location:** `internal/reedcli/header_test.go:121-127`
**Issue:** `TestHeaderCmd_BlockingTailParksAfterWatchError` checks `buf` for the substrings `"status"` and `"error"` to prove "no JSON envelope ... was written", but `output.Ok` (internal/output/output.go:17-22) injects `"ok":true` and the caller's own `"text"` key — never `"status"`. With the missing-`return` bug above, this test currently passes even though a JSON envelope (`{"text":"...","ok":true}`) is appended to the capture buffer after the rendered text.
**Fix:** Assert against the JSON-envelope shape actually used (e.g. check `buf` does not contain `"ok":true` beyond the initial byte count, or compare the buffer's full contents equal exactly the rendered-text prefix with nothing appended).

## Verdict

REQUEST_CHANGES
header.go's blocking tail lacks a return after headerPark(), letting a JSON envelope leak onto the pane's console if headerPark returns.
