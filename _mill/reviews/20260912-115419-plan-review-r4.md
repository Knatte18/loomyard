## Findings

### [BLOCKING:scope] New mandatory `selfreport` key silently poisons the existing smoke suite with real GitHub filings
**Location:** Batch 3, Card 9 (interacts with pre-existing `internal/loomcli/smoke_test.go`, not in this plan's file list)
**Issue:** `smoke_test.go`'s `fastDeadlineLoomConfig()` builds its fixture loom.yaml from `loomengine.ConfigTemplate()` verbatim (only overriding `discussion_timeout_min`), and the file's own header states every test in the suite intentionally bounces Discussion-Write to `shedengine`'s default bounce budget and then blocks — i.e. `State: blocked`, `Error: "bounce budget exhausted"`, exactly `AnomalyBudgetExhausted`'s trigger (`internal/loomengine/anomaly.go` per card 5). These tests run the REAL compiled `cmd/lyx` binary as a subprocess (`buildLyxBinary`/`runLoomCLINoFatal`), not `RunCLI`-in-process, so there is no seam to swap `selfreportengine.NewGitHubClient`. Once `Config.Selfreport` defaults to `true` (card 4) and `drive.go` wires the real `selfreportengine.CreateIssue` unconditionally (card 9), every run of `go test -tags smoke ./internal/loomcli/...` on a machine with a resolvable GitHub token (e.g. `gh auth login`, explicitly named as a fallback in `selfreportcli`'s own help text) will attempt to file a real issue against `Knatte18/loomyard` — silently, since the warn-and-continue posture (Shared Decision) means the test still passes.
**Fix:** Add a card (or extend card 9) updating `fastDeadlineLoomConfig()` (or `newWiredPairFixture`'s seeded config) to override `selfreport: false`, and state this explicitly as a Shared Decision or card requirement — the template comment card 4 adds already anticipates "a run … in CI must set it false" but nothing in the plan applies that to this repo's own smoke fixture.

### [BLOCKING:scope] Card 4 omits updating four pre-existing hand-typed config fixtures that the new mandatory key breaks
**Location:** Batch 1, Card 4 (`internal/loomengine/config_test.go`)
**Issue:** `TestLoadConfig_DiscussionInteractiveTrue`, `TestLoadConfig_MalformedDiscussionSpec`, `TestLoadConfig_MalformedPlanSpec`, and `TestLoadConfig_MalformedReviewSpec` each hand-type a full 7-line YAML block with no `selfreport:` line. Once card 4 adds `selfreport` as a template key, `configengine.Load`'s `yamlengine.MissingKeys` check (`internal/configengine/config.go`'s `load`) fires "missing keys: selfreport" for all four *before* `LoadConfig` ever reaches `yaml.Unmarshal`/`modelspec.Parse` — so `DiscussionInteractiveTrue` gets a non-nil error where it asserts nil, and the three `Malformed*Spec` tests get an error not containing "discussion"/"plan"/"review" where they assert it does. This breaks `go test ./internal/loomengine/`, which is in batch 1's own `verify:`.
**Fix:** Card 4's Requirements must explicitly add a `selfreport:` line to these four hand-typed YAML fixtures (or switch them to `writeLoomConfigWithKey`, which already builds off `ConfigTemplate()` and would pick up the new key automatically).
