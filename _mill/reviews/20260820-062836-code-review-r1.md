### [NIT:design] Publish takes `prs[0]` from a State:"all" query with no explicit sort
**Location:** `internal/landingshed/publish.go:145-178`
**Issue:** The pull-request query uses `State: "all"` (needed to distinguish closed/merged from closed/unmerged) but does not set `Sort`/`Direction`, so if more than one historical PR ever existed for the same head/base pair (e.g. a closed one followed by a new one), `prs[0]` is not guaranteed to be the most recent.
**Fix:** Set an explicit `Sort: "created", Direction: "desc"` on the list options, or document why exactly one PR per head/base is assumed to always hold.
