## Findings

### [BLOCKING:design] Card 15's three new fixture helpers are unnamed
**Location:** Batch 4 / Card 15 (`watchdogreap_integration_test.go`) **Issue:** Card 15 introduces three new symbols — the shared hub/engine fixture builder, the compressed-timing constructor, and the worktree-deletion helper — describing each only by role ("the batch's shared fixture helper", "a compressed-timing helper", "the worktree-deletion helper") with no function name or signature, unlike every other card in this plan (card 9's `dispatchReap`, card 7's `planReapCycle`, card 6's `worktreeRootGone`/`hubIsLiveDir`) which names its new symbols explicitly, and unlike cards 16-19 which will need to call these three by name. **Fix:** Name each of the three new helpers and give a signature, so card 15's implementer and cards 16-19 (which consume them) share one identifier instead of each inventing its own.

### [NIT:consistency] ReapSession's addition makes ListSessions' own doc comment false
**Location:** Batch 1 / Card 2 (`internal/reedengine/overlay.go`) **Issue:** `ListSessions`' existing doc comment states "It is the one engine-less, exported function in this package" (verified in `internal/reedengine/overlay.go`, `ListSessions`'s doc comment, lines 106-112); once `ReapSession` ships as the package's second engine-less exported function — which Card 2 itself requires `ReapSession`'s own doc comment to say — that sentence in `ListSessions`' comment becomes a superseded, false statement, and no card asks to update it. **Fix:** Add a bullet to Card 2 updating `ListSessions`' doc comment to drop or rephrase the now-false "the one" claim.
